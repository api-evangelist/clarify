Clarify is an AI-native CRM platform that automates sales workflows, integrates with email, calendar, and various tools, and provides a conversational AI assistant to manage contacts, deals, and pipelines. It offers a JSON:API‑compliant API for programmatic access to CRM data, enabling custom integrations, automation, and AI‑driven insights for sales teams.

**Areas:** Company · CRM · Artificial Intelligence · Automation · Sales

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Clarify: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
